# Sts2HollowKnightAudio

用于《杀戮尖塔 2》空洞骑士模组的 FMOD Studio **2.03.06** 音频工程。

- 54 个音效事件：法术、剑技、蓄力、角色动作、梦境与召唤物攻击音效。
- 17 个音乐事件，包含虚空之心的 108 秒双声部定时编排。
- `Package/` 提供自定义 bank 和 GUID 映射；`Integration/` 提供 RitsuLib 接入示例。

打开 `HollowKnightAudio.fspro` 编辑；运行 `Build.ps1` 构建并校验事件。
详细使用方法、来源说明和虚空之心音乐编排见 [中文说明](README.zh-CN.md)。

基础工程：[STS2_FModProject_Minimal](https://github.com/BAKAOLC/STS2_FModProject_Minimal)。
接入参考：[添加音频教程](https://tutorials.sts2modding.com/docs/04-ritsulib/04-10-add-audio/)。
